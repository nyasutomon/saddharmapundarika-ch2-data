# SMSR II transcriptions are not distributed

The 12 SMSR II transcription files have been excluded from this public
repository and its Git history because permission to redistribute them
has not been obtained. This directory contains no transcription text.
Rights remain with the SMSR II editors, publishing body and respective
rights holders. Redistribution requires their permission.

Use lawfully obtained transcriptions from an external private directory
when running the audit. Do not upload them here. See RIGHTS.md and
scripts/README.md.
