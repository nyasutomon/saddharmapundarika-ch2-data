# Generic legacy character mapping

Only the generic legacy font-to-Unicode character mapping is distributed.
The 12 text-specific offset/span annotation files are excluded alongside
the SMSR II transcriptions. The public audit runner requires them from an
external private directory to reproduce the original font-unit calculations.
