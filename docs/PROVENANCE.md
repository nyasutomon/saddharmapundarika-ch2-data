# Source provenance

Release curator: Yasutomo Nishi. Prepared 10 October 2026 for ASCJ 2027 research.

The supplied aligned electronic transcriptions are associated with:

Tsukamoto, Keisho; Taga, Ryugen; Mitomo, Ryojun; Yamazaki, Moriichi; and
Kawazoe, Yoshiyuki. 1988. *Sanskrit Manuscripts of Saddharmapuṇḍarīka
Collected from Nepal, Kashmir and Central Asia: Romanized Text and Index*,
Vol. 2. Tokyo: The Society for the Study of Saddharmapuṇḍarīka Manuscripts (SMSR II).

The retained digital release has verse file dates of 20260731, prose and
whole-chapter dates of 20260807, and Pr1/Pr2 dates of 20260803. File dates identify
the supplied digital versions, not manuscript dates or SMSR publication dates.
The 24 CSV files are the original supplied outputs. Their source-file byte hashes
are recorded in `metadata/input_manifest.json`.

Chihiro Mayuzumi developed the original text-comparison programs. The code here is
an independent reconstruction of the audit performed in this research session.
The original production program and its complete settings are not supplied.
The release therefore distinguishes regenerated audit values from the original exports.

The electronic source may differ from printed SMSR and later editions. Such
differences are retained. Reproducing an electronic input does not independently
verify a manuscript letter, editorial restoration, or historical interpretation.

Encoding annotations document the correspondence between each supplied UTF8 file
and the legacy input used in the audit. Offset coordinates count Unicode code points.
Each record gives offset, Unicode length and the original non-ASCII byte value.
Unannotated ASCII text remains unchanged. Each restored input is checked against its
original SHA256. No private filesystem paths are included.

Original-export licence: CC BY 4.0 with Chihiro Mayuzumi's permission, confirmed
by the depositor on 10 October 2026. This covers the exported CSV files, not
the original program source or SMSR II transcriptions. See RIGHTS.md.

Public-release exclusion (10 October 2026): the SMSR II UTF8 transcription
files and text-specific restoration annotations are not distributed because
redistribution permission has not been obtained. The numerical results retain
their original audit provenance. Recalculation requires external private inputs.
